LayerOptics: Interactive Multilayer Thin-Film Designer

An interactive Python software application for designing and simulating multilayer thin-film optical structures using the Transfer Matrix Method. Users can build custom layer stacks, explore TE and TM optical response, calculate reflectance, transmittance, and absorptance spectra, and export the results as CSV files. Try the live application.
